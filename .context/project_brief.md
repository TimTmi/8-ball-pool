# Project Brief: 8 Ball Pool

## Goal
A simple mobile 8 ball pool game (pass-and-play local multiplayer, no online features). It's a top-down 2D game focusing purely on gameplay with a minimalistic UI (Main Menu and Gameplay screen only). Players control aim angle and power concurrently via touch dragging, with standard 8-ball rules and a strong emphasis on physics, realistic spin control, and advanced trajectory prediction.

## Stack
- Unity (C#)
- Mobile target (iOS/Android)
- Unity Physics 2D

## Core Features
- Local pass-and-play multiplayer
- Conventional pool table and standard 8-ball rules
- Minimalistic UI: Main Menu (Play, Credits, Quit), Gameplay screen
- Top-down 2D view
- Precise touch controls: drag anywhere to set aim angle and power simultaneously
- Lock buttons for aim angle and power (bottom left corner)
- Spin control (top right corner)
- Explicit "Shoot" button (bottom right) unlocked after tap release
- Advanced trajectory prediction showing ball path and spin effects
- Realistic, decent physics
